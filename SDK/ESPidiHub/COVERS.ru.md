# Обложки

English: [COVERS.md](COVERS.md).

Обложка — картинка 64×32, которую ESPidi HUB показывает, пока запускает вашу прошивку, и миниатюра прошивки на сайте-сборщике.

```
 ┌────────────────────────────────┬────────────────────────────────┐
 │                                │ MY ARP                         │
 │        обложка, 64×32          │ 1.2.0                          │   OLED 128×32
 │                                │                                │
 └────────────────────────────────┴────────────────────────────────┘
```

Справа HUB выводит имя (до двух строк по 10 символов) и версию. Без обложки — только имя.

## Как рисовать

- **64×32 пикселя, чёрно-белая. Белое горит.** Прозрачное считается чёрным.
- Подходят и кратные размеры — 128×64, 192×96, … Каждый блок 2×2, 3×3, … станет одним пикселем, горящим, если в нём хотя бы половина белого. Удобно, если редактор плохо увеличивает.
- Название прошивки в картинку не пишите: HUB выводит его рядом. Нужен рисунок, логотип, знак — то, что узнаётся за полсекунды.
- Серого на OLED нет. Полутона — дизерингом (шахматка, пунктир); результат проверяйте в превью на сайте.
- Рисунок чёрным по белому: конвертируйте с `--invert`, перерисовывать не нужно.
- Уже есть массив для Adafruit GFX `drawBitmap()` с картинкой 64×32 (image2cpp: *Horizontal – 1 bit per pixel*)? Это ровно формат обложки.

## Где она лежит

В репозитории по SDK (см. [FIRMWARE_GUIDE — Публикация](../../docs/FIRMWARE.md#публикация)) обложка — **один файл в репозитории**, указанный в `espidi.json`:

```json
{ "espidi": 1, "sketch": "MyArp", "firmware": "espidi/MyArp.ino.bin", "cover": "cover.png" }
```

Всё остальное берётся из этого файла:

| Кто | Откуда берёт обложку |
|---|---|
| сайт-сборщик, вкладка **GitHub** | `cover.png` из репозитория, из того же коммита, что и прошивка |
| `espidi_hub.py install --slot N owner/repo` | оттуда же |
| сама прошивка | `<sketch>/cover.h`, сгенерированный из `cover.png` |
| HUB на плате | то, что установщик записал рядом со слотом; иначе обложка внутри прошивки; иначе только имя |

При установке обложку всё равно можно заменить или убрать (сайт: «Загрузить» / «Убрать»; CLI: `--cover`, `--no-cover`).

## Как встроить в прошивку

```bash
python3 <ESPidi-HUB>/tools/espidi_hub.py repo . --sync-cover   # пишет <sketch>/cover.h по espidi.json
```

```cpp
#include <ESPidiHub.h>
#include "cover.h"   // ESPIDI_COVER(...) — 256 байт, сгенерировано, не править
```

Workflow шаблона запускает `--sync-cover` перед каждой сборкой, поэтому опубликованная прошивка всегда несёт обложку из репозитория; локально запускайте после правки `cover.png`. Без репозитория: `espidi_hub.py cover picture.png > MySketch/cover.h`.

Обложка занимает 268 байт флеша. Без `cover.h` у прошивки просто нет встроенной обложки.

## Проверка

```bash
python3 <ESPidi-HUB>/tools/espidi_hub.py repo .               # локальная копия
python3 <ESPidi-HUB>/tools/espidi_hub.py repo owner/repo      # то, что увидит сайт
```

Ошибка — если обложки нет или размер не тот; предупреждение — если обложка внутри опубликованной прошивки отличается от `cover.png`.

## Формат

1 бит на пиксель, строки сверху вниз, 8 байт на строку, старший бит — левый пиксель, 1 = горит — 256 байт. Внутри прошивки: `ESPIDI-CV-1\0` + эти 256 байт (`ESPIDI_COVER`). Для HUB хранится в разделе `espidi`. Раскладка байтов: [docs/ARCHITECTURE.md](https://github.com/Cirocular-Vlasenko-Daniil/ESPidi-HUB/blob/main/docs/ARCHITECTURE.md).

# ESPidi

ESPidi — открытая MIDI‑платформа на ESP32 для создания собственных MIDI‑инструментов.

Коротко: готовая плата с MIDI I/O, OLED‑дисплеем, органами управления и аккумом, а также примерной прошивкой, которую можно модифицировать или использовать как основу для своих устройств.

Особенности
- Поддерживаемые приложения в прошивке: арпеджиатор, мелодичный секвенсор, секвенсор песен (song), MIDI‑монитор, MIDI‑clock (Start/Stop/Continue).
- OLED UI, поддержка сохранения параметров и паттернов (LittleFS + EEPROM).
- REST‑free, лёгкий и минималистичный код на Arduino/ESP32.

Аппаратная платформа
- ESP32‑C3 Super Mini
- OLED 128×32 (планируется 128×64 в будущем)
- Энкодер с кнопкой
- 3 тактовые кнопки (L/R, TAP, PLAY)
- MIDI IN / MIDI OUT (DIN‑5 или MiniJack)
- Встроенный аккумулятор

Example Firmware
Репозиторий содержит пример прошивки, демонстрирующую возможности платформы:
- Arpeggiator (ARP)
- Melodic Sequencer (SEQUENCER)
- Song Sequencer (SONG)
- MIDI Monitor (MONITOR)
- MIDI Clock + Start/Stop/Continue
- OLED UI и управление энкодером/кнопками
- Сохранение настроек и паттернов (EEPROM + LittleFS)

Разработка
- Прошивку можно развивать с нуля или на основе примера.
- Поддерживаемые инструменты: Arduino IDE, PlatformIO, ESP‑IDF.
- Код написан в стиле Arduino для простоты портирования на ESP32‑C3.

Кому это будет полезно
- Музыкантам и разработчикам DIY‑инструментов
- Тем, кто хочет быстро прототипировать MIDI‑контроллеры, секвенсоры, арпеджиаторы и MIDI‑эффекты
- Тем, кто хочет экспериментировать с прошивками на одном аппаратном наборе

Быстрый старт
1. Склонируйте репозиторий: git clone https://github.com/EugeneCarlo/ESPidi.git
2. Откройте проект в Arduino IDE или PlatformIO.
3. Подключите плату ESP32‑C3 и загрузите прошивку.
4. При необходимости поменяйте пины в config.h под вашу плату.

Файлы и структура
- Основные модули прошивки: arp, seq_mel, seq_song, midi_handler, clock_engine, ui, hardware, inputs, settings
- Конфигурация пинов и настроек — config.h

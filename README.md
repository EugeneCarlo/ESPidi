# ESPidi

**ESPidi — открытая MIDI-платформа на ESP32 для создания собственных MIDI-инструментов.**

Готовое доступное железо с MIDI I/O, OLED, органами управления и аккумулятором. Прошивку можно изменять полностью или использовать собственную.

## Аппаратная платформа

* **ESP32-C3 Super Mini**
* **OLED 128×32**
* энкодер с кнопкой
* 3 тактовые кнопки
* MIDI IN / MIDI OUT — DIN-5 или MiniJack
* встроенный аккумулятор
* 3 свободных GPIO с ограничениями текущей конфигурации

Будущая версия предусматривает OLED **128×64** и дальнейшее расширение аппаратной платформы.

## Example Firmware

Репозиторий содержит **Example Firmware**, демонстрирующую возможности платформы:

* Arpeggiator
* Melodic Sequencer
* Song Sequencer
* MIDI Monitor
* MIDI Clock
* MIDI Start / Stop / Continue
* OLED UI
* сохранение настроек и данных

Example Firmware не является фиксированной прошивкой устройства. 
Её можно изменять, использовать как основу или полностью заменить собственной реализацией.

## Разработка

Собственную прошивку можно разрабатывать с нуля или на основе Example Firmware.

Поддерживаются любые подходящие для ESP32-C3 инструменты, включая **Arduino IDE, PlatformIO и ESP-IDF**.
